# 策略驗證

run_strategy_backtest 只執行平台既定策略，不是任意策略程式引擎。確認標的、區間、費率與滑價，bps 為萬分之一。使用者未提供費率時，說明研究假設，不稱實際券商費用；ETF、個股交易稅不同，不猜特殊資格。

核對完成 K 線及實際期間，缺分鐘線不製造資料。下一根開盤成交、ATR 停損、2R 目標、同根停損優先是模型規則，不是保證成交。

查看交易筆數、獲利虧損分布、回撤及成本敏感度，不只看報酬／勝率。交易稀少限制結論；多期間結果分列，不把挑出的最佳期間當獨立驗證。

目前未完整模擬排隊、漲跌停、流動性與公司行動，也無歷史當時可得財務／籌碼版本。不能把最新報表或組合放進過去訊號，不能宣稱已驗證所有多因子策略。不自編預測勝率、未來 K 線或收益保證。

留存時引用行情／回放 evidence_id 保存報告；用 show_stock_chart 引導真實日 K，不畫捏造未來路徑。
