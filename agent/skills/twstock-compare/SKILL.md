# 比較與研究整理

先以search_stocks分別核對所有名稱／代號，不因平台目前選股而替換任何一家公司。同業候選先查peers與產業，再確認業務差異；同產業分類不代表收入組成或風險相同。ETF和公司分開分析，不把ETF自身套入公司EPS或營收成長排名。

依問題選共同比較期間、財報頻率與價格基準；逐欄列資料日期及缺值。不混合月營收年增、季度獲利率與全年EPS作同一時間結論。跨股即時快照可能不同秒，不能宣稱同步套利或完全同時價格；優先以共同完成交易日比較。ETF配息率不是總報酬，若缺淨值、費用、持股或含息序列，標明不能比較的部分。

用簡短比較表呈現可比指標、各自支持／反對證據及適用情況。數字缺漏用無資料，不填零、不用現成名次或固定權重硬算總分。使用者未要求排名時，不必勉強選唯一贏家。

需要留存時以save_research_report保存Markdown與本輪實際查詢evidence_ids。每一檔都寫出名稱／代號與資料期間；不要把A公司的財務數字或價位套到B公司。報告不強制七個章節，回答問題所需內容即可；工具拒絕時核對引用或價位再修正，不能用刪除負號或改成含糊詞規避檢核。
