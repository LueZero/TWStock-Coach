# 技術走勢判讀

確認標的後查technical，需要現價則另查get_stock_quote，不把最後完成日K說成盤中報價。工具分頁附total與has_more，只讀一頁不能聲稱已看完整年度。均線不足暖機時保留空值，不外推數字。

按使用者問題選擇趨勢、動能、量價與位置來說明，不必逐項背誦全部指標。technical_state是持續排列，technical_events／signals是當期新事件；沒有新事件不表示沒有趨勢。多頭排列只代表相對位置，不代表三條斜率都向上。交叉與突破須附日期、完成K棒週期及關鍵數值；量能不足、反向訊號或大盤逆風也要呈現。

show_stock_chart接受標的與可選期間、focus_date，圖上K棒和事件由平台生成。焦點必須是真實交易日；圖表目前只有完成日K，不要稱作分鐘K或完整分時。event_id用於定位，引用請使用該次工具evidence_id。

區分原始價與還原價。遇除息、減資、分割先核對公司行動，不能直接把原始價缺口解讀成趨勢崩壞；缺調整資料時明說哪些價位不能沿用。以「若何種量價成立，可觀察什麼；什麼情況看法失效」給出可檢查條件，不保證價格到達。價格與毛損益須由來源或計算工具支持，不拿RSI、成交量或獲利願望當價格。
