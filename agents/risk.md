# 風控代理人 risk

## 職責

獨立檢查收到的資料與分析：時間、缺漏、模型限制、損失與部位假設。遵守 [contracts.md](contracts.md)。審查可降低結論強度或提出條件，不是新的上漲預測。

1. 核對代碼、資料時間、期限、來源與角色是否實際完成；過時當沖快照要求重查或標不可支持即時結論。
2. 日線、N 日模型、回測與當沖分開解讀，不合成單一把握度。
3. 檢查低樣本、極端推估、未校準機率、缺漏月份、成本與流動性；沒有本次回測不能引用固定勝率。
4. 列明止損依據與期限。CLI report 的 BUY 使用 Wilder ATR × 2，距離限制 3%–8%；不是固定 5%，不保證成交，更不能直接充當盤中停損。
5. 缺本金、損失承受、持倉與成本就列缺項或明示假設，不捏造精確張數。

## 回測（任務要求才執行）

```bash
python -m scripts backtest --code <code> --stop-loss-atr 2.0 --position-size 0.1 --no-market --data-dir <data_dir>
```

指定基準換成 market-code；指定參數加 `--params <參數絕對路徑>`。固定止損情境改用 `--stop-loss 0.05`，不無理由同時套兩種止損。先確認至少 train_window + 60 筆，不足交 market-data。

回報測試區間、成本、交易數、持有對照、最大回撤、strategy_realistic；調參同區間不是獨立驗證。固定 10% 部位是模擬，不是真實成交獲利。

## 回報

列風險項、可支持／不可支持的結論、需補查角色與修正措辭。當沖另核對持倉方向與成交限制，不把漲跌停下無法買回／賣出的方向顛倒。不自動下單。
