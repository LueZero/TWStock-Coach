# 股票計算機與同業比較

更新：2026-10-11，版本1.2.0。計算機由主菜單獨立開啟，同業比較仍位於個股研究頁。

目前介面僅保留「手續費折數」及「每筆最低手續費」兩個費用設定。基礎費率採0.1425%，交易稅依商品、交易模式及日期自動套用，元以下採捨去；後端的進階參數保留供擴充，介面不再要求填稅率、取整方式或其他成本。

費用、交易稅與交易級距本次已核對官方來源，日期到期後的規則仍需追蹤法規更新，見 [檢視報告](REVIEW_2026-10-11.md)。新增測試核對整股／ETF級距邊界的雙向可逆跳檔、零股、雙邊最低費、先賣後買及損益兩平；不判定帳戶資格，也不限制情境價格在當日漲跌停內。

同業預設以目錄產業分類作候選；已核對的業務比較組會優先使用較接近的公司。目前友達2409與群創3481使用「大型顯示面板製造」組，依據公司官方產品／年報資料整理，並非交易所細產業分類。畫面顯示名單依據及來源；其他未建立業務組的股票明確標示為大分類候選，可手動調整，不能假設全是直接競爭者。

目前修訂視角首次顯示比較名單時，會自動循序補抓未接收的來源，優先本檔及業務相近公司，每家公司在同一頁面工作階段只自動嘗試一次。只在實際送出工作時記錄已嘗試，未處理名單不會被誤標為已嘗試。手動補齊按鈕保留作重試。歷史可得視角不自動補抓；新取得資料不會回填為當時已知。僅兩家公司時有效同業樣本只有一個，中位數仍標為樣本不足；實際公司數值可以正常並排比較。

股票計算機位於桌機側欄／手機頂部主菜單，是獨立中央工具頁；同業比較保留於個股研究分頁。兩者跟隨頂部搜尋選取股票，計算機標題顯示目前股票，不顯示個股行情與研究導覽。切換股票會清除上一檔試算價格及比較結果；計算機與比較有自己的日期與設定，不顯示無關的K線區間控制。

## 計算機

提供買入成本、賣出實收、一般買入後賣出、當沖先買後賣與先賣後買。張數轉為股數：1張＝1,000股；一般交易可選股數輸入零股，現股當沖限定整張數量，同數量全數沖銷。商品稅別由使用者確認，代號以00開頭只預選一般ETF，不猜測是否為債券ETF。

- 成交金額＝每股成交價×股數。
- 每邊手續費＝（成交金額×費率×折數÷10）取整後，與每邊最低費用取較高值。
- 交易稅只在賣出邊計算，以賣出成交金額×適用稅率取整。
- 買入現金流＝負成交金額－買入手續費；賣出現金流＝成交金額－賣出手續費－交易稅。
- 平倉淨損益＝買賣現金流合計－其他成本。單邊不產生平倉損益。

Node.js使用decimal.js十進位運算，API以金額字串傳回，避免零股與折扣的浮點誤差。手續費與稅各提供捨去／四捨五入／進位至整元；最低費用每邊一次。0.1425%及20元僅為可調整預設，非券商統一標準，也未模擬先收全額再退折扣、多筆成交或分單。

股票一般賣出0.3%；符合條件的現股當沖0.15%優惠至2027-12-31；非債券ETF0.1%；債券ETF免稅至2026-12-31。超過優惠期限採一般稅率，可自行覆寫；須核對屆時新規。依據：[TWSE投資指南](https://www.twse.com.tw/zh/about/company/guide.html)、[ETF規則](https://wwwc.twse.com.tw/zh/products/securities/etf/overview/rules.html)、[現股當沖規則](https://www.twse.com.tw/zh/products/system/day-trading.html)。此工具不判定當沖帳戶／標的資格，零股不適用現股當沖，不包含融資融券。先賣後買未回補時的借券費、強制買回與差額另計，未以零假設包入試算。

一般／先買後賣報酬率以買進成交金額加手續費為分母；先賣後買以賣出實收為分母，明示不是保證金報酬率。損益兩平價以固定第一筆、搜尋第二筆淨損益不小於零，再依股票／ETF升降單位調整；可重新代入驗證，並非目標價。帶入行情僅用原始價，列出快照或歷史K線日期，不用還原價當可成交價格。

## 同業比較

依股票目錄的產業分類直接帶出完整候選名單，已核對的業務相近公司優先排序。畫面每頁10檔，可搜尋、篩選業務組、移除或新增公司；分頁不截斷完整比較資料。不同市場可以比較，跨產業公司會標示且不計同產業中位數。產業分類很粗，半導體可能含晶圓製造、設計與材料，不能冒充相同商業模式；金融等產業需自行選擇合適指標。

比較指標：本益比、股價淨值比、來源殖利率、月營收年增率、單季EPS、毛利率、營業利益率、負債比率。表格依估值／營運／結構分組，避免一次塞入十多欄；另提供指標切換、條形比較、數值與期間、來源接收時間與修訂。

預設共同期間：以所選股票每個資料集的最近期間為基準，其餘公司須有同期間資料才顯示可比較值；個別公司的資料缺漏，不得清空其他公司的資料。月營收依營收年月，同季財報依財務期間；找不到同期間不硬拿不同年份比較。各自最新模式仍列各公司日期，中位數只納入與本檔相同期間的有效同產業公司。至少2家比較公司才提供中位數，不含本檔，缺值不補零。業務相近篩選時中位數只計已核對的業務組；其他模式明示為產業大分類中位數。

資料截至日限制財務期間；歷史可得視角另限制平台接收時間，現在取得的修訂不回填成當時已知。估值超過14天、月營收超過100天、財務指標超過200天不計比較中位數。個別列保留過期狀態與原資料日期。EPS為單季非TTM，單季EPS不能拿來當規模／股東報酬排名；低本益比不直接判好。

「補齊名單財務資料」循序使用既有工作佇列，顯示進度與來源結果，避免同時大量查詢。歷史可得視角不啟動回填。來源缺權限、配額或網路失敗時保留缺漏；切換股票會停止頁面後續排隊與舊回應覆寫，已送出的背景擷取仍依原股票完成。

完整名單會立即帶出，未接收的來源在目前修訂視角自動循序補齊；資料不可能繞過來源配額立即取得。單家公司來源失敗會保留缺漏並繼續，連續三家公司失敗停止本批；切換歷史視角停止後續排隊。可稍後用按鈕重試；頁面關閉後只保留已送出的工作，不繼續前端排隊。景碩3189、欣興3037、南電8046列為IC封裝載板業務組，三家公司互相優先顯示及擷取。

## 買賣價、幾檔與比例試算

當沖的買入與賣出價格都可輸入，留空幾檔時依實際買賣價試算。填入正負幾檔或點選情境後，先買後賣以買價為起點自動更新賣價，先賣後買以賣價為起點更新買回價；手動修改平倉價會清除已選情境，不強制覆寫。

跳檔模式自動依商品與當下價格逐檔計算，不需填每格價差。股票六級距依序為未滿10元0.01、10～未滿50元0.05、50～未滿100元0.1、100～未滿500元0.5、500～未滿1000元1、1000元以上5元。向下跨界採下方級距，例如100元往下99.9、1000元往下999；向上為100.5及1005。38元每檔0.05，一張未扣費稅為50元／檔。ETF另依50元界線使用0.01／0.05，不套股票千元5元規則。

比例模式保留獨立上漲、下跌每格設定：上漲0.5%、下跌0.25%、各3格為−0.75%、−0.5%、−0.25%、0%、＋0.5%、＋1%、＋1.5%。每列以進場價為基準，不複利，再依商品升降單位四捨五入。表格分列設定比例、實際合法價格、實際漲跌及扣成本淨損益，可能因升降單位而不同。這是價格假設，不是預測、漲跌停或下單資格檢查。
