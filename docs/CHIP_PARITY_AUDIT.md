# 籌碼分析與 CMoney 九個分頁內容核對

核對日期：2026-10-11；參考股票：友達2409；目前程式版本：1.2.0。

本文件保留改版前的欄位核對。九個子頁與新增來源已依此實作，當前功能及限制請讀[個股籌碼工作區](CHIP_WORKSPACE.md)，下表「目前平台」欄為改版前狀態。

本文件是實際頁面核對與後續實作規格，不代表九個分頁已完成。檢視 CMoney 訪客可見的九個頁面，以及本專案 `web/index.html`、`research-view.js`、`api/equity.js`、載入工作和實際 API 回應。一般網頁工具八頁回傳403，因此改用隱藏 Chrome 正常瀏覽指定網址，九頁均取得公開內容。未登入；券商分點停在登入提示，未確認其完整欄位、互動及圖表細節。其餘圖表的精確配色、所有下拉選項及內部計算公式也未逐項確認，不宣稱完全一致。

這只是同日樣本核對，不保證全歷史數字一致。每日合計須先加總原始股數再換算／四捨五入；不能把已取整的三欄相加。例如本平台此日合計為-67,948.855張，取整為-67,949張。

目前友達集保資料只有2026-10-08一期，因此可以呈現占比，不能顯示前週變動或連續趨勢。最新免費快照不等於已取得歷史。

## 現有設計需要修正的地方

1. 籌碼目前是四個長區塊，混合每日流量、每週股權與基金揭露；改成九個子頁，每次呈現一個主題。
2. 卡片為使用者選定區間，`view()`卻將彈窗history改成全部已取得歷史。彈窗應預設與選定區間一致；額外顯示長期歷史時需明確切換。
3. 法人每日明細沒有三大法人合計，也沒有同一圖直接切換／比較。任一必要組成缺值時合計留空。
4. 分點明細目前只彙總區間內最新一天，不能稱為區間排行。單日與區間兩種模式要明確分開；各價格成交逐日合併後再按分點彙總。
5. 可查詢分點數與基金揭露數是覆蓋資訊，移到來源狀態，不作為主要籌碼指標。
6. 基金數history使用累積曾出現的基金代號，不是當日實際持有基金數。改為同一日可確認且股數大於零的持倉；不同揭露頻率不得隨意補齊。
7. 原籌碼說明寫成綠色淨流入、紅色淨流出，但實際CSS已採紅色淨買超、綠色淨賣超。本次已修正文案。紅綠只表示方向，不表示買入或賣出建議。

## 畫面規格

沿用個股頁，不另開瀏覽器分頁。股票、日期、股／張與資料視角共用。

- 子菜單：法人買賣、主力進出、券商分點、籌碼分布、大戶散戶、融資融券、董監持股、申報轉讓、ETF／基金持股。桌面可排兩列，手機分行，不把九張大卡片一次往下堆。
- 每個子頁上方：最新可用日期、選定區間、觀測筆數、更新狀態。每日數據明確標示盤後，不跟盤中報價混在一起。
- 中間：少量主指標加一張直接可見的主圖；股價與股數／百分比各用自己的座標軸。切換指標時圖表與明細同步。
- 下方：區間明細與必要的排行，歷史趨勢可放大；來源、定義、缺漏收在展開區。
- 不強制所有長表在一個螢幕完整展開；主指標和主圖優先可見，表格採分頁，避免擠壓圖表。

## 資料接入與計算契約

| 類別           | 可用／候選來源                               | 條件與限制                                                              |
| -------------- | -------------------------------------------- | ----------------------------------------------------------------------- |
| 法人與外資存量 | 現有FinMind法人及外資持股                    | 已接入；盤後資料；投信、自營商存量尚無來源，不從流量推算                |
| 主力與分點     | 現有FinMind集中度及專用分點接口              | 集中度前15大、單位股；需Sponsor，完整資料才可推算其他統計               |
| 大戶散戶       | 現有集保快照；FinMind歷史分級                | 免費快照逐週保存；過往分級需要可用歷史來源與相應權限                    |
| 融資融券       | FinMind `TaiwanStockMarginPurchaseShortSale` | 官方文件已有欄位；需新增adapter、單位核對與持久化，不直接套現有股數換算 |
| 董監／轉讓     | 公開資訊觀測站／交易所公開揭露為候選         | 尚未確認適合批次接入的端點、歷史範圍與欄位；必須先完成來源驗證          |
| ETF／基金      | 現有主動ETF／手動匯入；投信公開揭露為候選    | 無完整被動ETF／共同基金來源；各基金揭露時間不同，權重不能跨基金相加     |

依[FinMind文件](https://finmind.github.io/tutor/TaiwanMarket/Chip/)，現有集中度資料只有前15大買超股數、前15大賣超股數；不能直接得到買賣家數差。建議自有集中度定義為「N個完整交易日的前15大淨流向總和／相同交易日成交股數總和×100%」，標示「本平台前15大集中度」；在未核實 CMoney 公式前不宣稱同口徑。資料缺漏或不足N日留空，滾動指標可在展示起日之前載入暖機資料，但輸出不超出選定區間。

[集保官方說明](https://original-www.tdcc.com.tw/portal/zh/smWeb/qryStock)以每週最後一個營業日ID歸戶編製。前週變動以百分點呈現；占比基準是來源揭露的集保庫存，不能不加說明改成已發行股數。小於20張與20張以下在級距邊界不同；若原始級距無法精確拆出20,000股邊界，畫面應使用可計算的實際定義，不拆分估算。

融資／融券餘額取截止日值，區間淨變化使用期末減期初，不把每日餘額加總。券資比以融券餘額／融資餘額×100%，融資餘額為零時留空。使用率需限額；借券與融券分開。參考頁的「當沖比」分母尚未核實，不能直接換成現股當沖率。財務公司設質比、個人設質比各自保留分母，法人代表的持股不重複計入法人持股。

所有數量保留原始來源單位，正規化後再提供股／張切換；期貨口數不進入個股籌碼計算。每筆保留來源、基準日期、公告／揭露時間（若有）、接收時間與修訂。區間無事件、來源未接入、無權限、只有單一期、資料過期、來源錯誤須分開呈現。

## 實作順序與驗收

1. 先拆九個子頁，完善已有法人、集保資料的主圖／明細與門檻，修正區間同步及覆蓋資訊位置。
2. 新增個股融資融券；確認來源原始單位、餘額與使用率，與同日官方資料交叉比對。
3. 接入董監持股與申報轉讓；先確認來源契約、歷史能力與角色去重，再做圖表。
4. 取得完整分點與基金揭露後再補集中度、分點區間排行及基金月變動；無授權資料時明確保留缺值。

驗收至少涵蓋友達、台積電、景碩與一檔上櫃股票；單日／跨休市／自訂區間；股張換算；零值與缺值；集保只有單一期；前週與暖機資料在區間外；改選股票後舊資料清空；五日／二十日以完整交易日計算。這次僅完成核對文件與顏色文案修正，其餘是待實作規格。
