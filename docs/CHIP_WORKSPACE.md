# 個股籌碼分析工作區

沿用個股股票搜尋、日期區間、股／張與歷史資料視角，在同一頁中央提供九個子頁。前端 `chip-workspace-view.js` 負責子頁、主圖、表格及分頁；後端 `chip-workspace.js` 計算統一資料結構，`ownership-provider.js` 轉接官方揭露。

| 子頁          | 已實作內容                                                           | 資料條件                                               |
| ------------- | -------------------------------------------------------------------- | ------------------------------------------------------ |
| 法人買賣      | 合計／外資／投信／自營／比較圖，每日淨買賣超與區間合計，收盤價右軸   | 現有法人來源；合計缺任何組成留空                       |
| 主力進出      | 前15大淨買賣超、5／20日集中度、家數差欄位與收盤價                    | 前15大來源需Sponsor；家數差未確認完整來源與口徑，留空  |
| 券商分點      | 單日／區間排行、買超／賣超排序、搜尋、前15排行圖、全部表格、人別趨勢 | 需Sponsor；區間僅合計已取得日期，列出觀測天數          |
| 籌碼分布      | 大戶400／1000張切換，外資持股對照、週股價、完整集保級距              | 投信／自營商／董監存量占比尚缺同口徑來源，不從流量推算 |
| 大戶散戶      | 大戶逾400／1000張，散戶20／50張以下，比例雙線、前期百分點變化        | 歷史資料不足時變化留空；級距邊界不拆分估算             |
| 融資融券      | 融資餘額／融券餘額／券資比切換，增減、使用率、互抵與收盤價           | FinMind個股來源；原始數量張，輸出轉股；非現股當沖率    |
| 董監持股      | 月份／身分篩選，人別持股、設質、關係人原始資料與歷史彈窗             | 官方最新月份逐次保存；持股占比來源未提供，留空         |
| 申報轉讓      | 方式篩選，揭露日期、數量、身分、有效期間、事件數量圖                 | 官方近期公開日報逐次保存；不保證過去事件完整           |
| ETF／基金持股 | 搜尋、股數、權重、前月觀測變化、基準日、基金歷史                     | 指定主動ETF或已匯入來源；不代表完整基金市場            |

## 官方來源與時間

- 上市董監持股：[TWSE t187ap11_L](https://openapi.twse.com.tw/v1/opendata/t187ap11_L)。
- 上市轉讓：[TWSE t187ap12_L](https://openapi.twse.com.tw/v1/opendata/t187ap12_L)。
- 上櫃董監持股：[TPEx mopsfin_t187ap11_O](https://www.tpex.org.tw/openapi/v1/mopsfin_t187ap11_O)。
- 上櫃轉讓：[TPEx mopsfin_t187ap12_O](https://www.tpex.org.tw/openapi/v1/mopsfin_t187ap12_O)。
- 法人、集中度、資券與分級定義：[FinMind籌碼資料文件](https://finmind.github.io/tutor/TaiwanMarket/Chip/)。

資料月以當月1日作儲存索引，另保留 `period_month` 和官方 `published_at`，畫面以月份顯示，不把1日當成交易觀測日。申報轉讓的公開出表日不冒充真實申報日。上櫃轉讓的股票代號、日期和身分欄位與上市不同，轉接分別處理。原始揭露及接收時間沿用不可變快照和修訂，歷史視角仍以平台已接收時間限制。

## 數字與缺值

數量統一回傳股；顯示張保留三位小數。合計先加總原始值再格式化。股價使用獨立右軸；缺值使折線中斷。大戶／散戶前期比較可能相隔多週，需核對明細日期，不宣稱連續週資料。只有一期可畫單點但不產生前期變化。

集中度是本平台明確定義的前15大淨流向／同期成交量，使用完整N筆交易日及展示區間前的暖機價格；缺少來源值就留空。未宣稱與CMoney主力公式相同。資券餘額是存量、不跨日加總；使用率與券資比分母缺漏或為零時留空。

基金權重只對同一基金比較，來源未給持股金額時留空，不能把現在股價乘上過去持股宣稱歷史揭露金額。最新零持股不列入持有基金。人別及基金表格可點開既有趨勢視窗，預設資料落在所選區間；董監採截止日前已保存的月份揭露。

## 驗證

`npm test`包含五項籌碼計算回歸：完整級距與門檻、法人缺值／分點聚合、資券單位及比率、集中度暖機、基金權重比較與官方日期欄位。

`npm run verify:chips`驗證九個子頁、股張換算、20／50張門檻、單日區間、董監彈窗、切換股票及1440／1024／390／320寬度。截圖：[個股籌碼分析](../web/public/images/screenshots/stock-chips.png)。

本版完成九個子頁的介面與可用資料接入；不是CMoney會員資料、所有歷史覆蓋或專有公式的完整複製。參考欄位核對見[前期核對文件](CHIP_PARITY_AUDIT.md)。
