# 財務分析：五類、38 細項與資料契約

更新日期：2026-10-11，版本1.2.0。分類、細項名稱與順序依使用者提供的財報狗選單逐項對齊。選單對齊不代表資料覆蓋、公式或會員功能完全一致。本平台採 FinMind 與官方文件入口，不使用財報狗會員資料。

## 閱讀與排版

五大分類維持頂端切換。桌面左側列該分類的細項與可用狀態，右側只呈現所選細項；手機改成下拉選單。細項先呈現精簡指標摘要，接著是多條指標比較圖、同期間數值表，最後才放原始報表證據。金額、百分比及倍數分圖，不能混用同一刻度。

圖表支援多指標勾選、自訂起訖與全部歷史；表格同步篩選，可選4／8／12期或區間全部，並往較早／較近期間翻頁。金額可切元／千元／億元，原始儲存仍為元。區間與比較選擇按股票與細項保存，資料刷新不會重設。各指標摘要仍可開啟獨立歷史彈窗。缺資料不補成零。資料來源、接收時間與修訂另設收合區塊。

## 必須保留的計算口徑

- ROE：單季本期淨利除相鄰季末平均總權益；另列近四季ROE。主頁ROA加回同季稅後利息，稅率採所得稅／正值稅前淨利且需介於0～100%；資料或稅率條件不足便留空。舊API純淨利ROA保留但不作主頁參考口徑。
- 杜邦：同季淨利率 × 單季資產週轉 × 平均資產／平均權益。即使最新損益和資產負債期間不同，也不混用最新值。
- 週轉：單季營收／成本除以相鄰季末平均存量，未年化。主頁應收含帳款、票據與關係人，任一必要科目缺漏不假設零；天數採參考平台季報的90日／週轉率。舊API的一般應收及實際日數指標保留但不混入主頁。
- 費用：總營業費用、推銷／管理／研發只採可辨識科目。來源不拆分時不按比例反推；研發下降不直接標成改善。
- 合約負債：流動合約負債期末存量對同季營收流量；年增比較去年同季，增加不等於已實現獲利。
- 流速動：必要科目缺漏不設零；速動需扣存貨、預付款。長期資金占固定資產採不動產廠房設備，不用全部非流動資產替代。
- 利息保障：同一現金流報表期間（稅前淨利＋利息費用）除正值利息費用；零／缺費用不設無限大。
- 現金流：Q1使用來源值，其餘季需前季及相同年初現金餘額才能將年度累計差分；未確認累計基準不差分。現金流量分析看單季營業現金／同季流動與總負債兩個比率。現金對淨利另列單季及完整年度版本，不用半年累計現金流除單季淨利。
- 資本支出：核對來源原始名稱後只計已辨識設備取得支出，畫面明示其涵蓋限制。自由現金流為部分資本支出參考。盈再率另採當季權益法投資加固定資產減四年前同季兩項，除近16季淨利；不是設備支出除單季淨利。
- 股利：來源配息事件逐筆呈現，核對盈餘年度、公告／除息／發放日，不把最近單筆當全年。
- 成長：季報營收、毛利、營業利益、稅後淨利同時列單季及近四季年增；後者須連續8季，去年合計為正。基期為零／負數不計百分比。合約負債列年增與季增。原始EPS未必共用股數基準，不直接加總TTM或計算調整後年增。
- 估值：本益比、PBR、殖利率採來源值與同檔歷史位置；不以固定倍數判便宜，也不用日殖利率平均冒充平均股息殖利率。

## 配色與比較規則

紅表示改善／強勢；綠表示衰退／虧損；黃表示需留意；藍灰表示需要背景或缺資料。利潤率同季改善標紅、下降標綠，週轉效率採相同期間比較。費用減少、槓桿增加、合約負債增長及投資／籌資流量不能單看正負定好壞。

流速動比低於100%、業外比重達50%、利息保障1～3倍與年度營業現金低於正值淨利是可見的研究提醒，並非普遍適用的買賣門檻。銀行、保險和ETF不能套一般製造業標準。缺值不判成公司衰退，不回復已移除的公司總分或健診建議。

## 後續分析資料契約

`GET /api/fundamentals/{market}/{symbol}` 除原有資料外提供：

- `catalog.version / groups / pages`：38 個穩定 ID、分類、科目、指標引用、閱讀口徑與依賴原因。
- 狀態：`available`、`partial`、`no_data`、`dependency_missing`、`reference`。有相關資料不會解除被阻擋主計算的狀態。
- `metrics[].comparison`：同去年同期的基準、日期、數值、差異與差異單位，百分點與百分比分開。
- `metrics[].assessment`：色調、文字與原因；`metrics[].datasets` 對應 `coverage` 的來源、接收時間、修訂及快照 ID。
- `analysis_contract`：版本、缺值不是零、平台取得時間可用性、期間不得混算等前提。後續助手應依這些欄位查證，不能讀顏色猜結論。

`as_of` 繼續先限制快照接收時間，再限制報表日期。最新下載不能放回過去假裝當時已知。圖表自訂區間只過濾可見修訂的數值，不把報表日期當公告時間。請求約五年，實際覆蓋依商品與來源。
