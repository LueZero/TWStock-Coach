# 財務細項內容核對

原始核對：2026-10-10；文件檢視更新：2026-10-11，版本1.2.0。依使用者貼上的38項選單及先前可公開讀取的財報狗頁面核對。這份紀錄區分「頁面已接入」與「內容完全一致」，不能用選單數量表示完成度。原站需登入的完整歷史及會員功能未取得；本次未重新逐頁核對外部網站或新增會員資料。

每股淨值、現金股利發放率、EPS成長率、本益比河流圖、股價淨值比河流圖、平均現金股息殖利率、平均現金股息河流圖。畫面保留頁面並列缺少條件，只呈現已取得的參考資料，不用普通折線冒充河流價格帶。電子書另為官方文件入口，未匯入可核對PDF清單。
