# 加權指數與台指期

主菜單「大盤市場」提供獨立中央內容頁，不另開瀏覽器分頁。桌機菜單在側欄，手機在頂部；個股功能導覽與個股價格不出現在大盤頁。分為即時走勢、技術分析、籌碼分析三個子頁，股票與大盤的商品及日期控制獨立。

## 行情與圖表

桌機大盤採視窗高度排版：行情摘要與控制列縮成橫向，走勢與五檔並排；技術卡片位於走勢右側；籌碼比較圖與明細並排。已驗證1024×768、1280×720、1366×768、1440×900及1920×1080，預設收合說明時主要資訊不需要上下或左右捲動。手機與較低視窗保留正常閱讀，不靠縮成小字或遮住資訊達成同屏。

台指期與個股五檔共用 `web/src/views/orderbook-view.js` 和 `.book-table` 樣式，欄位一致為委買量、委買價、檔、委賣價、委賣量；共用字體、買紅賣綠、掛單深度色帶與五檔合計。桌機數字18px，響應式規則與個股一致，矮桌機僅縮小兩者列間距。掛單色帶以目前可見五檔最大數量為相對基準，不代表全市場買賣力道。期貨數量以口表示，1口是1份期貨契約；委託是尚未成交的掛單，可能撤銷，不是成交量。資料切換與載入中清除舊五檔與合計，缺值顯示「—」，不將未揭示檔位當成零。

歷史指數摘要以億股與億元顯示；數值提示保留原始股數及金額。指標／來源長說明點開浮層閱讀，保留圖表空間。

三張行情卡顯示最新取得的加權指數、台指期日盤及夜盤。台指期明示契約月份、開高低、本盤參考價、成交口數與未平倉口數。日夜盤的漲跌各以官方本盤參考價計算，不能直接當成與現貨的價差。

最近一盤使用期交所公開行情網站的快照、1分鐘開高低收與五檔。可切換1／5／15／30分鐘及1小時K，選擇K線或走勢線，開關MA5／20；游標查看數值、拖曳移動、滾輪縮放及重設。均線使用完成觀測，1小時K依日盤08:45或夜盤15:00起點聚合，未結束的尾端K線保留未完成狀態。

勾選自動更新後每15秒檢查；僅在此頁可見且來源尚未標示收盤時更新。休市顯示最近一盤及來源日期，不標示為當下成交。來源不是授權逐筆串流，來源中斷時明示先前資料。

## 歷史區間

技術分析子頁使用獨立起訖日，一次最多367個日曆日期，僅顯示有資料的交易日。圖表與下方數值依區間；上方三張卡仍標示最新快照。另讀取180日曆日暖機，MA5／20／60、Wilder RSI14、MACD（12／26／9）只使用完成觀測；不足期數顯示缺值。指數日線沒有官方開高低，因此不假造 KD 或 ATR。

加權指數使用證交所FMTQIK月報的歷史收盤值、成交股數與成交金額，來源沒有日開高低，僅提供收盤走勢線。台指期歷史日K使用FinMind TaiwanFuturesDaily，指定TX、契約月份與position／after_market盤別，缺資料不以其他月份代替。

指數沒有委託五檔，成交量不使用期貨口數。歷史日線不帶入現在的五檔。夜盤分鐘圖保留官方盤別日期及15:00至翌日05:00的順序；沒有可靠交易日歸屬欄位時，不自行把盤別日期轉成交易日期。歷史日K則保留FinMind來源交易日期。

## 籌碼分析

依所選日期查詢，初始採最近指數行情的官方日期，避免週末自動顯示空白。法人買賣、融資融券與台指期法人分成子選單，提供數值卡片、比較圖與明細表。

- 上市法人：證交所 BFI82U，金額以億元顯示；外資自營商與合計保留於明細，不重新加總進圖表。
- 融資融券：證交所 MI_MARGN；來源仟元換成元再顯示億元，交易單位保留原單位。列出前日／今日餘額及增減，不讓不同單位共用同一圖軸。
- 台指期法人：期交所 OpenAPI，交易多空口數與未平倉淨額分開。來源只有最新日資料；歷史指定日期不存在即明示缺漏，不套用最新資料。

紅色／綠色表示淨增減，不代表買賣指令；籌碼於收盤後公布，不是盤中即時成交。台指期法人日統計包含全契約，不冒充特定月份或夜盤專屬進出。

## 後端

- GET /api/market/board：日夜盤及現貨指數快照。
- GET /api/market/chips?date=YYYY-MM-DD：各來源的籌碼數據、可用性、統計日期與接收時間。
- GET /api/market/board/chart：product=index／day／night；mode=intraday／history。分鐘查詢指定對應盤別symbol，歷史期貨指定YYYYMM契約與起訖日。
- market_board_snapshots保存來源鍵、摘要、首次接收時間、最近觀測時間last_seen_at、標準化數值及分鐘來源原始payload。來源內容相同不新增快照，只更新最近觀測時間；不同內容另存，原始內容不覆寫。內容A→B→A後，服務重啟且來源失敗時按最近觀測時間回讀A，不誤回B。
- 同鍵請求合併；公開行情快取15秒、當月指數5分鐘、歷史月份24小時、期貨歷史1小時。來源失敗可回讀先前快照，標示stale及warning。
- 行情表與指數快照分開，避免期貨口數混入股票股數。既有股票資料與資料卷不重建。

## 驗證與來源

啟動Compose及Vite後執行 `npm run verify:market`。後端解析與前端聚合測試包含跨年契約、夜盤跨午夜、缺值、未完成K線與期貨開盤聚合。

`npm run verify:market-layout` 檢查五種桌機視窗的三個子頁、籌碼各分類、沒有頁面捲動、卡片內容未溢出、完整五檔與字體大小；另核對390／320像素手機無水平溢出。

來源：[期交所公開行情](https://mis.taifex.com.tw/futures/)、[證交所市場成交資訊](https://www.twse.com.tw/exchangeReport/FMTQIK?response=json&date=20261001)、[FinMind期貨日成交文件](https://finmind.github.io/tutor/TaiwanMarket/Derivative/)。免費介面與會員資料的可用性仍依來源規範。
