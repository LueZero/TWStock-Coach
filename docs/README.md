前台有三個主菜單：個股看盤、大盤市場、股票計算機。策略回放在個股研究分頁；預測目前只有API。財務與籌碼趨勢彈窗保留，綜合健診／評分／建議視窗已移除。Grafana、舊後端與前端靜態目錄不屬於現行架構。

文件中的「有入口」、「公式已實作」、「本次來源有資料」、「完整資料覆蓋」是不同狀態。新增功能須同步記錄缺值、來源、日期、權限與驗證方法；不能用選單數量或舊測試數字表示現行完整度。正式部署結果、付費來源、盤中行情與備份還原須按實際環境另驗證。
