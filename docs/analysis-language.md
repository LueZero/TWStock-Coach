# 分析結果的白話呈現

這份文件只定義輸出語言，不決定任務分派、指標門檻或角色職責。

## 呈現順序

1. 公司／代碼、分析期限、資料截至時間（Asia/Taipei），分開列盤中價與日線收盤價。
2. 一句白話結論，再列 2–3 項有來源的關鍵證據。
3. 只呈現實際執行過的分析；技術、財務、新聞、ML、當沖的證據不要混成同一分數。
4. 風控結論、明確假設、過時／缺項及無法支持的推論。
5. 「⚠️ 以上分析僅供參考，不構成投資建議。」

## 術語

| 名詞 | 白話與限制 |
|---|---|
| MA／EMA | 過去價格的平均或加權平均，描述趨勢而非保證方向。 |
| KD／RSI／CCI | 最近價格的動能或偏離程度，極端值不等於立即反轉。 |
| MACD | 兩條快慢均線的差與變化，屬歷史趨勢摘要。 |
| ADX／DMI | 趨勢明顯程度與方向，須分別看。 |
| ATR | 日常波動尺度，可用作風控距離參考。 |
| 支撐／壓力 | 歷史價位結構，不保證價格會停在那裡。 |
| 型態候選 | 滿足幾何規則的形狀，仍須確認量價與突破。 |
| 預測報酬 | 模型估計指定交易日後的漲跌幅，實際可能不同。 |
| prob_up | 模型輸出的上漲分類機率；不是投資獲利勝率，未校準不得稱可靠把握度。 |
| confidence 價位範圍 | 程式依近期波動估計的區間，不自動具有 95% 等統計涵蓋率。 |
| BUY／HOLD／SELL | 模型條件式訊號，可解釋偏多／觀望／偏弱，不說「一定要買賣」。 |
| 停損價 | 預先規劃的損失控制參考，跳空與流動性不足可能無法按該價成交。 |
| 勝率 | 指定回測期間內賺錢交易的比例，須附交易數與成本。 |
| 最大回撤 MDD | 指定期間資產從高點到後續低點的最大跌幅，不是本金最終虧損或保證上限。 |
| Sharpe | 報酬相對波動的摘要，受期間、頻率與假設影響。 |
| strategy_realistic | 採指定部位比例的回測模擬，仍不是真實成交績效。 |
| 三大法人 | 外資、投信、自營商，不等於券商分點主力。 |
| 本益比／股價淨值比 | 價格相對獲利／帳面淨值，應搭配產業與營運條件。 |
| 殖利率 | 股利相對股價的比例，不保證未來配息或總報酬。 |
| 月營收 MoM／YoY | 營收相較上月／去年同月的變化，不是淨利增減。 |
| ETF 基本資料 | 追蹤指數與基金資訊；現有工具缺 NAV 折溢價等欄位就直說沒有。 |
| 五檔委買委賣 | 當下排隊的價量，掛單可改變，不等於已成交買賣力道。 |
| 今日振幅 | 當日高低價差相對昨收，不是此後還能賺的空間。 |

## 常見提問

- 「該買嗎？」：列各來源支持／不支持的證據、期限與缺項；涉及資金配置時說明個人條件尚未知。
- 「會漲多少？」：若實際執行模型，就附實際 days_ahead、推估及限制；沒跑就不補數字。
- 「今天能沖嗎？」：由當沖角色確認日期、新鮮度、成交與成本限制，不能拿日線分數代答。
- 「為什麼準／不準？」：列本次真正使用的模型、樣本、特徵與驗證結果，不固定宣稱三年資料、0050 或某個勝率。
