# 回測方法 Backtest

## Walk-Forward 切分

```
Day 0 ──────────────── Day 120 ─── Day 125 ─── Day 130 ───...
[─── train_window ───][predict][predict][predict]
                     │  step  │  step  │
```

- `train_window=120`：每次用前 120 天訓練
- `step=5`：每 5 天重新訓練一次
- `days_ahead=5`：每次預測未來 5 天累積報酬
- 嚴格時序：訓練集永遠在預測集之前，無未來資料洩漏

## 進出場規則

```
進場條件: 預測訊號 = BUY  →  以隔日開盤價買進
出場條件（任一觸發）:
  1. 持有 days_ahead 天後到期
  2. 跌破止損價 (見下方止損設計)
  3. 漲破止盈價 (預設關閉)
交易成本: 0.5% (雙邊)
```

## 止損機制（Phase 4 / 6）

### 固定止損
```bash
python scripts/backtest.py --code 2330 --stop-loss 0.05
```
所有股票統一 5% 止損，簡單但無法適應個股波動。

### ATR 動態止損（推薦）
```bash
python scripts/backtest.py --code 2330 --stop-loss-atr 2.0
```

計算方式：
```python
TR  = max(high-low, |high-close_prev|, |low-close_prev|)
ATR = rolling_mean(TR, 14)
atr_pct = ATR / close

# 進場時計算個別止損
effective_stop = entry_atr_pct * 2.0
```

**實測 ATR×2 結果**：
| 股票 | 自動算出的止損 % |
|------|------------------|
| 2330 | 4.17% |
| 2308 | 6.83% |
| 2454 | 5.21% |

低波動股縮緊、高波動股放寬，避免被正常波動洗出場。

## 複利模型（Phase 6 關鍵修正）

回測有兩種輸出：

### `strategy`（傳統複利）
每次全倉重投，會出現「總報酬 32000%」這種數字。**只能看趨勢，不能信絕對值**。

### `strategy_realistic`（推薦）
```bash
python scripts/backtest.py --code 2308 --stop-loss-atr 2.0 --position-size 0.1
```
- 每筆只用 **10% 固定初始資金**
- 不複利重投
- 對應「分散投資」的實戰邏輯

**對比範例（2308 / 3 年）**：
| 指標 | strategy (複利) | strategy_realistic (10% 部位) |
|------|----------------|-------------------------------|
| 總報酬 | 32847% | 67.47% |
| MDD | -61% | -5.23% |
| 含意 | 紙上幻覺 | 接近實戰可達 |

**👉 看報告請以 `strategy_realistic` 為準。**

## 關鍵指標解讀

| 指標 | 公式 | 看的標準 |
|------|------|---------|
| **Direction Hit** | 預測方向對的比例 | >55% 不錯、>60% 很好 |
| **MAE** | 預測誤差絕對值平均 | 越小越好 |
| **Win Rate** | 賺錢交易筆數 / 總筆數 | >55% 不錯 |
| **Sharpe** | 年化超額報酬 / 年化波動 | >1 不錯、>2 很好、>3 極佳 |
| **MDD** | 史上最大資金回撤 | 越接近 0 越穩 |
| **Buy & Hold** | 對照組（一路抱不動） | 我們的策略應該贏它 |

## 與真實交易的差距

回測**無法**模擬：
- 滑價（限價單成交困難）
- 流動性不足（小型股大單買不到）
- 開盤跳空（止損可能跳過）
- 心理因素（連虧 5 筆會不會手抖）
- 突發新聞停資/熔斷

實戰請預留至少 1-2% 的緩衝。
