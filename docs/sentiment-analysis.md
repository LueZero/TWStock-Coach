# 公開新聞輿情分析

## 用途

`python -m scripts sentiment` 從 Google News RSS 查詢近期公開新聞，依股票代碼與公司名稱比對標題，輸出來源、時間、連結、關鍵詞與保守的情緒摘要。綜合報告也會顯示最近 3 則結果。

```bash
python -m scripts sentiment --code 2338 --name 光罩 --days 7
```

## 方法與範圍

- 資料來源為 Google News RSS 聚合的公開新聞標題，不爬取封閉社群、私人群組或留言。
- 排除排行、零股成交量等明顯雜訊標題，並對重複標題去重。
- 可追溯詞典計算正面、負面與中性或訊號不足；輸出每篇命中的關鍵詞。
- 輿情不寫入技術分析分數、不作為 ML 特徵，也不產生 BUY/SELL 指令。

## 準確性限制

標題詞典無法理解反諷、否定句、文章全文與事件實際影響，也無法驗證新聞真偽。文章少、來源集中或分數接近零時，應解讀為訊號不足，而不是「市場中性」。RSS 的收錄時點與可用性也可能改變。使用者應自行開啟輸出的原文連結確認事件內容。
