# 技術面分析功能盤點

## MVC 設計

| 層級 | 位置 | 責任 |
|------|------|------|
| Model | `scripts/technical/indicators.py` | 從 OHLCV 日 K 計算指標、量價與價位結構。 |
| Model | `scripts/technical/patterns.py` | 以固定條件偵測 K 線與圖表型態候選。 |
| Controller | `scripts/technical/controller.py` | 集中訊號規則、分數權重與多空結論。 |
| View | `scripts/technical/views.py` | 將 `AnalysisResult` 呈現為 JSON 或 Markdown，不含交易判斷。 |
| 相容入口 | `scripts/technical_analysis.py` | 提供 CLI 與既有 `TechnicalAnalyzer` API，委派給 MVC 模組。 |

資料流：OHLCV CSV -> Model -> Controller -> `AnalysisResult` -> View / `report_generator.py`。

## 價格區間候選掃描

`python scripts/stock_screener.py --min-price 25 --max-price 35 --min-volume 1000000` 先以 TWSE 上市普通股最近可用交易日的收盤價與成交量篩選，再對成交量最高的候選抓取歷史日 K，套用同一套 Controller 技術訊號排序。輸出的 `as_of` 是實際收盤日期；`screen_close` 是篩選用收盤價，`technical_close` 是最後一根日 K 收盤價，`realtime_close` 則是即時 API 回傳價。`realtime_status=no_latest_trade` 表示 API 未提供最新成交價，應以 `screen_close` 視為最近收盤。此結果為技術面候選與風控參考，不是保證今日上漲或預測固定上漲金額；目前範圍不含上櫃、ETF、權證。

## 綜合訊號規則

目前會納入多空統計的訊號：MA、EMA、KD、MACD、RSI、CCI、布林、肯特納、ADX/DMI、OBV、價量關係、VR、葛蘭碧、季線背景、BIAS 極端值、支撐附近長下影線與中等信心型態。型態須同時為 `medium` 信心且當日量大於等於 5 日均量才計分；低信心型態只展示為候選。多方分數比空方至少多 2 分時為「偏多」；空方同理；其他狀況為「中性」。

ATR 與支撐/壓力用於風險與價格位置判讀，不直接投票，避免同一種價格波動資訊被重複加權。

## 尚未實作的增強項目

以下項目屬於可選強化，而不是目前基本分析缺失：

- 週線與月線確認：目前以 MA60 近似季線背景；若需要明確週/月 K，須彙整日 K 或使用對應資料源。
- 產業相對強弱：目前未納入技術系統；若新增，應採可追溯的同產業指數或同業群組，而非以 0050 取代產業基準。
- 回測校準：每個指標或組合的有效性應用 walk-forward 回測，以不同股票與市場狀態驗證。

## 使用限制

- 型態偵測以 ZigZag 顯著轉折及 ATR 動態容許度產生「候選」，不是對未來的保證；必須由突破、量能與停損確認。
- 道氏、Elliott Wave、Wyckoff、Adam 是完整分析框架，沒有通用且無歧義的自動辨識定義。系統提供其可量化部分（趨勢、量價、結構），不產生主觀浪型或主力意圖的斷言。
- Controller 對一般訊號記 1 分；ADX 明確趨勢、均線穿越和中等可信型態記 2 分。多方或空方至少領先 2 分才標示方向，否則為中性。

## 資料與限制

- 日 K 資料來自 TWSE/TPEX 公開 API，須至少有 60 個交易日才能完整產生主要趨勢指標。輸出的 `data_as_of` 與報告的「技術資料截至」會標示實際採用的最後收盤日，不能將其視為盤中即時價。
- 技術分析會載入 `data/<股票代碼>_history.csv`；新抓取資料帶有 `stock_code` 標記，標記與請求代碼不符時會拒絕分析。舊版無標記快取維持依檔名相容，建議重新抓取以啟用來源驗證。
- 指標是歷史資料的統計摘要，不保證預測未來走勢；盤整與突發消息時假訊號可能增加。
- 技術面應與籌碼、基本面及部位風險管理一併使用；不得將單一訊號視為交易指令。

## 大盤法人資料

`python scripts/institutional_data.py --action market --days 20` 會逐日加總 TWSE T86 上市股票的外資、投信、自營商與三大法人淨額，提供當日、5/10 日累計與連買連賣統計。

此資料不含櫃買市場，亦非券商分點的「主力」買賣超。主力分點需要專用資料來源，不能從免費 TWSE/TPEX 公開 API 合理推導。
